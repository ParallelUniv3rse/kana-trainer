# Kana Trainer

Offline PWA for learning hiragana and katakana. See README.md for features, layout and hosting.

## Constraints

- No build step, no npm dependencies, no frameworks. Plain ES modules loaded by the browser. Keep it that way so the whole app stays a handful of static files the service worker can cache.
- Everything must work offline after first load. No CDN links, no remote fonts, no network calls at runtime.
- All paths are relative (`./`, `src/...`) so it works from a GitHub Pages subpath.
- When any served file changes, bump `VERSION` in `sw.js`. When a served file is added, add it to `FILES` in `sw.js`.
- `src/data/kana.js`, `src/fonts/kana.woff2` and `icons/*.png` are generated by `build/*.py`. Edit the scripts, not the outputs.
- The font is subset to the characters in `build_data.py`. New UI text with characters outside basic Latin, kana and the listed punctuation falls back to system fonts; add them to the subset text if they matter.

## Testing

Serve with `python3 -m http.server 8000` and open http://localhost:8000. For a phone-sized check use Chrome DevTools device mode. Offline: DevTools, Network, Offline, then reload.

Progress lives in `localStorage` under `kana.progress.v1`. Clear it to start fresh.

## Design

Indigo ink on cool practice paper. Characters always sit inside a practice square with dashed centre guides (`gridSvg` in `src/trace.js`); lesson nodes on the path use the same square. Colour tokens are CSS variables at the top of `src/styles.css`, with a dark-mode set below them.
